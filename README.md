# Mechanical-Keyboard
Half-life week 2 project

# What is it?

I have designed a custom 65% keyboard plate in CAD. It is only a plate, there is no case, the stabilizer cutouts are already made. I wanted to design a case as well however it was a little to advanced for my first time using CAD. That being said, I am happy with how it turned out and I hope that you like it as well!
